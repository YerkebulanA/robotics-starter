# Robotics Starter

A public collection of small robotics and computer-vision experiments.

## Topics

- OpenCV image and video processing
- YOLO object detection
- Object tracking and pose estimation
- Drone and Pixhawk experiments
- Python utilities for sensor data and automation

## Setup

```bash
git clone [https://github.com/YOUR-USERNAME/robotics-starter.git](https://github.com/YOUR-USERNAME/robotics-starter.git)
cd robotics-starter
python -m venv .venv
```

Activate the environment on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Install dependencies as projects are added:

```bash
pip install opencv-python ultralytics
```
